To convert your Python script into an executable (.exe), follow these steps using PyInstaller. PyInstaller bundles your script and all dependencies into a single executable file.

Step 1: Install PyInstaller
If you don't have it installed, open a terminal or command prompt and run:

pip install pyinstaller

Step 2: Prepare the Environment
Make sure all necessary dependencies (e.g., Pillow, piexif, tkinter, etc.) are installed:

pip install pillow piexif

Step 3: Build the Executable
Navigate to the directory where your script is located and run:

pyinstaller --onefile --noconsole pic_resizer.py
--onefile: Packages everything into a single .exe.
--noconsole: Hides the console window (useful for GUI applications).

Step 4: Locate the Executable
After the build process completes, you’ll find your .exe in the dist/ folder within the same directory as your script.

Optional: Custom Icon
If you want to add a custom icon to the executable, use:

pyinstaller --onefile --noconsole --icon=pic_resizer.ico pic_resizer.py

Step 5: Test the Executable
Open the dist/ folder.
Double-click the .exe file to verify that your GUI application runs without issues.
Troubleshooting Common Issues
Missing dependencies: If your .exe fails, ensure all dependencies (e.g., Pillow) are installed in your environment.
Hidden imports: Sometimes PyInstaller may miss certain modules. Use the --hidden-import flag if needed:

pyinstaller --onefile --noconsole --hidden-import=tkinter pic_resizer.py
